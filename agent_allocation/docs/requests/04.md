# Requests from agent 04 (text benchmarks)

## 04-R1 — `PrivateEvalSpec.allowed_choices` (contract field)

**Need.** Grading must accept `A` / `(A)` only when the letter is a legal option *for that item* (MMLU-Pro items
have 3–10 options; BBH choice tasks 4 or 7). `grade_text(candidate, private)` receives no `PublicTask`, and
`PrivateEvalSpec` carries no option list, so the grader cannot tell a legal wrong letter (`GRADED`, False) from an
illegal one (`INVALID_OUTPUT`, unknown semantics).

**Minimal change.** Append to `PrivateEvalSpec`:

```python
    allowed_choices: tuple[str, ...] = ()   # legal final identities for option/boolean items; () for MATH/code
```

A trailing default keeps every existing constructor call (agent 05's code specs) valid; `load_record` already
coerces `tuple[str, ...]`. The frozen-hash test changes with it.

**Shim until then.** `grade_text(candidate, private, *, allowed_choices=None)` (keyword-only, optional) reads
`allowed_choices` from the keyword, else from `private.allowed_choices` if the field exists. With neither, an option
final is checked only as a single letter `A`–`Z` (`detail_code="option_exact_unchecked"`). The grade worker
(agent 05) can pass `allowed_choices=task.allowed_choices` from the public manifest today. Once the field lands, the
adapters fill it (the private record hashed into `private_hash` already contains it) and the keyword becomes
redundant.

## 04-N1 — integration notes for `manifest.py` (no change requested)

- `benchmarks.<name>.source_record()` returns the dataset-lock facts (repo, revision/commit, file, sha256, rows,
  licence, preprocessing version) for each text benchmark.
- `benchmarks.text_manifest.exclusion_records(inventory)` is the engineering exclusion audit for
  `paths.exclusions` (currently one row: `mmlu_pro/8584`, `duplicate_option_text:A,D`).
- `bbh_logic4.load_inventory` copies the four pinned files plus `MANIFEST.json` into `paths.bbh_sources_dir`
  (write-once, verified against sha256 pins) and creates `paths.private_dir` with mode 0700 if needed.
- Panel sizes per benchmark for `balanced150`: `n_dev = panels.pilot_items // 4 = 8`,
  `n_main = panels.main_items // 4 = 100`, `n_reserve = 8`; seed `cfg["seed"]`.
- `grade_text` and `math_equivalent` bound Math-Verify with SIGALRM, so they must run on the main thread of a
  worker process; off the main thread they raise `EvaluatorUnavailable` instead of running unbounded.
