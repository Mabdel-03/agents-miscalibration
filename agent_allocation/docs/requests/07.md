# Requests from agent 07 (analysis, reports)

Analysis runs against local shims for each item below; none blocks M1/M2.

1. **Seal digest basis (contract §3).** Please pin `selections/{partition}.seal.json` `sha256` =
   sha256 of the `selections/{partition}.jsonl` file bytes. The loader currently accepts either that or
   `canonical_hash([dump_record(r) for r in records])` and records which basis matched; one pinned basis is safer.
2. **Provider `/key` usage snapshots in `state/`.** COST_RECONCILIATION reads `state/provider_usage.jsonl`,
   one object per line: `{"fetched_at": ISO-8601, "stage": "pre_pilot|post_pilot|pre_main|...",
   "endpoint": "key"|"credits", "data": <api data without label>}`. Also accepted: `state/key_usage_*.json`,
   `state/credits_*.json` holding one such object. Please confirm or give the layout you write.
3. **Independent recompute hook (agent 08).** `allocation audit` loads
   `tests/integration/independent_recompute.py` by path and calls
   `independent_recompute(run_dir: pathlib.Path) -> {"contrasts": {name: float|None}, "checks": [{"name", "passed", "detail"}]}`.
   Contrast names compared: `primary_i_peer_vs_private_team_n4_r4`, `primary_ii_cp_minus_private_team_gain_h3`
   (equal-benchmark macro, BBH subtasks equal). Please forward to agent 08.
4. **Config lock.** Analysis reads `locks/config.json` as either the raw config object (has `study_id`) or
   `{"config": {...}}`; otherwise it falls back to `configs/balanced150.json` and labels the report.
5. **Wave panel labels.** `Wave.panels` values are read as `main`, `extension`, `high`, `replication`, `pilot`;
   partitions map `main->main`, `high->high`, `replication->replication`, `pilot->pilot`; CP/POOLED checkpoints
   in `main` are checked against `extension`. Please confirm the labels `prepare-data` writes.
6. **Checkpoint names (agent 03).** Analysis parses `PolicyCheckpoint.name` (`sample/k`, `private_single/t`,
   `private_team/n/r`, `peer/n/r`, `deep/m`, `cp/h` including `cp/0`, `pooled/4`) and never parses `policy_id`
   (item ids contain `/`). `name` must be non-empty on every checkpoint.
