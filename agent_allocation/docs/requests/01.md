# Requests from agent 01 (OpenRouter adapter)

Nothing here blocks agent 01; the adapter works against the frozen contracts as they are.

## R01-1: policy for `TransportStatus.ERROR_ENVELOPE` (decision; `contracts.py` edit only for option b)

`ERROR_ENVELOPE` is in neither `RETRYABLE_TRANSPORT` nor `CIRCUIT_BREAKING_TRANSPORT`, so the scheduler has no rule
for it. The adapter returns it for an HTTP 2xx whose body is not one usable completion:

- a non-null top-level `error` (e.g. `{"error": {"code": 502, "message": "Provider returned error"}}`);
- a choice-level `error` (`finish_reason: "error"`);
- a malformed body: not JSON, zero or several choices, or a choice without `message`.

These are server-side failures, not model outcomes, and the charge is unknown (a truncated body may have been billed).

- (a) Keep the sets as they are. `ERROR_ENVELOPE` ends the attempt and the node fails; keep the reservation until
  reconciled, or `charge_max`.
- (b) Add `ERROR_ENVELOPE` to `RETRYABLE_TRANSPORT`, limited by `max_transport_attempts`. Keep the reservation as for
  `AMBIGUOUS_TIMEOUT`. Recommended, because a provider error inside a 200 is usually transient.

`error_detail` includes the embedded `code=` (for example `code=429` or `code=502`), so the scheduler can make a finer
choice without another contract change.

## R01-2 (informational): `contracts.Generator` does not describe the client

`Generator.generate(spec, messages)` doesn't match the frozen `OpenRouterClient.generate(spec, messages, *,
attempt_id, lock, sampling)`. Type the dispatcher against `OpenRouterClient`, or update or remove the Protocol.

## R01-3 (Gate 1 check): the served model must match exactly

`PROVIDER_MISMATCH` fires when the response's `provider` differs from `lock.provider_name`, or its `model` differs from
`lock.model`. Both comparisons are exact. The canary must confirm that OpenRouter returns
`"model": "google/gemini-2.5-flash-lite"` verbatim. If it returns a dated or canonical variant, amend the lock with
an explicit list of accepted served-model strings. Don't loosen the check to a prefix match: that would accept
`...-flash-lite-preview-09-2025` for a Flash-Lite lock and `...-flash-lite` for a Flash lock.

The response `provider` field cannot detect a tier change. `google-ai-studio`, `/flex` and `/priority` all report
`"Google AI Studio"`. Only `/generation` metadata `service_tier` shows the tier, so reconcile every canary and pilot
generation with `api.reconcile.reconcile_generation` or `metadata_identity_problems`.
