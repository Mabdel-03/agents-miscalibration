# Requests from agent 05 (MBPP+, sandbox, grading worker)

## R05-1 — `RunPaths.grade_cache_dir` (paths.py, lead-owned)

The grade/public-check verdict cache (keyed by revision, item, code sha256, test kind, evaluator version,
environment digest) needs a run-dir location. Proposed: `grade_cache_dir -> run_dir / "grade_cache"`, created 0700
by `ensure()` (it holds private-grade verdicts). Local shim until then: `agent_allocation.grading.worker.grade_cache_dir`.
It is deliberately *not* under `grades/`, so `grades/*/*.json` scanners only see GradeResult records.
