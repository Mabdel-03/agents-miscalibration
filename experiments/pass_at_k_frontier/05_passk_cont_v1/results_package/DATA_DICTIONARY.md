# DATA_DICTIONARY: passk_cont_v1 results package

Generated by `python -m agent_allocation.passk.export_package` (deterministic; re-run to refresh). Every CSV is UTF-8 with one header row and no index column; lists and objects are JSON strings; booleans are `true`/`false`; an empty cell is a missing value (for correctness: unknown).

Conventions used throughout: A = 1,024 reasoning tokens; an allocation `n x a` (config_id `NxA`, e.g. `4x4`) is n independent calls each forced to exactly a*A THINK tokens, answered with a 4,096-token ANSWER call, and read out by plurality over the calls' final answers (answer classes: exact vote key, then mutual complete-link Math-Verify; GPQA by option letter; ties by a seeded uniform draw). The mixture estimand weights benchmarks aime .10, hmmt .10, omni_math_hard .50, gpqa_diamond .30; macro weights them equally. Bootstrap = benchmark-stratified, item-clustered, 10,000 replicates, seed 20260925. Correctness is tri-state: true, false, unknown (empty; a 5 s Math-Verify timeout); invalid output counts as false.

- Purpose: Every item used anywhere (L96 u D32 u T200) with its panel memberships, provider shard, panel positions, strata and C48 sampling design.
