## geometry.py (§8.5)
`spectrum_metrics(X, standardizer=None, projector=None)` → raw norms, raw pairwise distances (min/mean/max), mean pairwise cosine distance on the centered + dev-standardized representation and on the unit-normalized vectors, nonzero covariance eigenvalues via the `s×s` Gram matrix, `participation_ratio`, `entropy_effective_rank` (also on the unit-normalized states), `rank_ceiling = min(d_eff, s-1)` carried on every estimate, `spectrum_testable = s ≥ 3`. `fixed_s_metrics(X, s, study_seed, item, config, count=100)`: exact when `n == s`, Monte Carlo mean (+ SD) over `count` hash-determined without-replacement subsamples (`HMAC(study_seed, ["GEOMETRY_SUBSAMPLE", item, config, k])` → `numpy.default_rng`) when `n > s`, `status="insufficient"` (never imputed) when `n < s`; the full-membership spectrum is kept as descriptive data. `Standardizer.fit` (dev states), `DevPCA(rank_requested=64).fit/fit_transform/transform` clipped to `min(rank, n-1, d)` with a sign-fixed, hashed component matrix (`components_hash`), `save/load` (`<base>.npz` + `<base>.json`); `display_transform()` is the separately frozen plotting map. `load_states(run_root, stage, blocks, anchor_kinds)` adapts `storage.load_stage` to the `(X, meta[id,item,method,role,phase,block,anchor,slot,…])` interface; `assemble_comparable_states(meta)` groups present vectors by (item, method, role, phase, block, anchor) and counts missing anchors; `ROLE_CONTRACTS` gives the guaranteed `s` (IND roots 5, DEC terminal/root members 5, CEN hub 1, worker 1 — hub and worker are separate roles, never pooled).

## readout.py (§8.8 family G)
- `build_feature_frames(run_root, "dev"|"confirmation", blocks, seal, panel_per_domain=150)` → `FeatureFrames(rows, X, blocks, stats)`; `assemble_rows(...)` is the disk-free core. Observables: method/superdomain/answer-format/stop-reason one-hots (fold-fitted vocabularies), selected personal confidence (dev-fold mean fill) + missing flag, sentinel flag, winning_count, tied_classes, all_singleton, valid/planned/pool counts, calls by role (root/revise/hub/worker/total), calls_admitted, spent/slack fractions of `B_flops`, task tokens, selected candidate JSON length, final-answer length, report prompt/evidence tokens, packet count, N.
- Text: `TextFeaturizer(prefer="auto")` uses the pinned `sentence-transformers/all-MiniLM-L6-v2` only when its snapshot is in the offline HF cache (the snapshot hash is recorded as the revision); otherwise fold-fitted TF-IDF (unigram+bigram, sublinear tf, l2) + TruncatedSVD-64 (`kind="tfidf_svd"` recorded). **The cache holds no sentence-transformers model, so the real run records `tfidf_svd`.**
- Neural: `NeuralFeaturizer(rank)` = fold-fitted `DevPCA` projections at rank ∈ {16,32,64,128} clipped to the training rank + `h_norm, h_log_norm, h_centered_norm`.
- `nested_cv(frames, GConfig)`: 5 outer × 5 inner folds from `grouped_stratified_folds` (clusters = source items; HMAC-ordered round-robin within superdomain); inner Brier selects `(block, rank, penalty)` with `one_se_select` (within one SE of the minimum: strongest penalty → shallowest block → smallest rank). Variants with the same folds/budget: `observables`, `baseline` (obs+text), `augmented` (obs+text+neural), `text_expanded` (obs+text+`rank_eff+3` extra TF-IDF-SVD dims = parameter-count-matched). Model: standard-scaled L2 logistic regression, `C = 1/λ`, λ ∈ {0.1,1,10,100,1000}.
- `freeze(frames, cfg)` reruns the selection on all dev, refits every variant and `FrozenG.save(<run_root>/neural)` writes `G_frozen.json` (selected block/rank/effective rank/penalty, per-variant coefficients + feature lists, observables vocabularies, text-featurizer pin, PCA `components_hash`, `arrays_sha256`, `sha256`) + `G_frozen.npz` (PCA mean/components, TF-IDF vocab/idf/SVD, expansion arrays). `FrozenG.load` refuses a modified artifact.
- `paired_cluster_bootstrap(values, clusters, superdomains, n_resamples=20000, seed, alternative="greater")`: clusters resampled with replacement independently per superdomain (multinomial counts), estimate = 0.5/0.5 superdomain-weighted item mean, linearized cluster SE, null-centered studentized one-sided p with the +1/+1 correction, 95 % percentile interval, `estimation_only` when < 30 clusters, `status="degenerate"` (no p, no zero-width interval) when the SE is zero. `confirmation_contrast(losses, seed)` averages the paired Brier difference over methods per item first (equal method weights).

## calibration.py (§8.7 family C)
`fit_recalibrators(dev_rows, seed)` → `FrozenC` with one `ScopeCalibration` per scope (`PERSONAL_FINAL` = selected personal confidence; `TEAM_SELECTED` = explicit `q_team_now`): dev marginal prior (source-item weighted), `common` map (intercept + clipped logit + missing flag) and `conditioned` map (+ fixed method intercepts) fitted with source-item grouped 5-fold CV over the common penalty grid and the one-SE rule; `primary="conditioned"` iff every method has ≥ 10 dev successes and ≥ 10 failures, else `common` with `threshold_failure=True` and the counts. Invalid/missing probabilities → prior + flag. `score_rows` gives raw / common / primary-recalibrated probabilities and Briers for both scopes; `contrast_C` = source-item-weighted mean Brier(baseline) − Brier(explicit) with the same bootstrap (plus the raw contrast), by-method contrasts and diagnostics per scope: weighted Brier, 5 dev-fixed reliability bins with source-item-weighted counts, signed bias, Cox intercept/slope and Murphy decomposition/AUROC through `analysis/nb_lib/calib.py` when importable (`backend` recorded), clipped log loss, missingness.

## Decisions recorded (not in the brief)
- Penalty convention: λ multiplies `0.5‖w‖²` against the *summed* log-loss (sklearn `C = 1/λ`), intercept unpenalized, features standard-scaled for G, raw logit for C. With ~180 dev rows the one-SE rule leans to strong shrinkage; both C maps and all G variants share it.
- The parameter-count-matched text expansion adds exactly `effective_rank + 3` TF-IDF-SVD dimensions (components after the baseline's 64) fitted in the fold; when the pinned sentence-transformers model is used the expansion is still TF-IDF-SVD (recorded).
- Confirmation panel = `split == "main"` items with `rank < --panel` per superdomain (the balanced rank prefix, §6.2); dev = the whole dev split (60 items).
- Geometry standardizer and display PCA are fitted per (block, anchor) on dev-item states pooled across roles; the fixed `s` comes from `ROLE_CONTRACTS`, unregistered (method, role, phase) combinations use their available count and are flagged `contract_registered=false`.
- R2's outcome-blind selection stores one call per (role, phase, episode), so the native store yields `s = 1` per role for IND/DEC unless the capture is extended to all roots/terminal members; the geometry stage then reports `status="insufficient"` (pairwise-only) rather than a dimension claim. The 5-root IND / 5-member DEC spectra need that capture extension.
- CEN_RLM is absent (not run); equal method weights are over the methods present.
