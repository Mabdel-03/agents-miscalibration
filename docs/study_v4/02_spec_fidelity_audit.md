## 2. Requirements checklist for retained tiers

Legend: **MUST** = execution contract (violating it invalidates the cell); **SHOULD** = reporting obligation; **CAN-DEFER** = post-Monday analysis on sealed artifacts.

### 2.0 Cross-cutting (applies to every tier)

1. **MUST** Candidate schema (§3.5; `schemas/candidate.schema.json`): exactly six keys, `additionalProperties:false`, evidence items {claim,support,uncertainty∈{low,medium,high,unknown}}, bounds 16,384/32/8,192/131,072, confidence finite in [0,1]. Parser: take vLLM `content` (post reasoning-parser), strip surrounding whitespace, strip **one** enclosing ``` fence (with optional `json` tag), `json.loads` with `object_pairs_hook` that raises on duplicate keys, reject trailing text, reject NaN/Infinity (`parse_constant` raise), then validate. Any failure → `parser_status=INVALID_<reason>`, candidate ineligible, scored 0, opportunity kept.
2. **MUST** Failure sentinel (§3.5): a revision whose parent is invalid receives exactly `{"status":"unavailable","failure_code":"NO_VALID_PARENT"}` in the own_saved_candidate slot; a missing/unfinished infrastructure artifact is `INCOMPLETE` and never converted into this sentinel.
3. **MUST** Semantic seed (§3.6): `seed128 = HMAC-SHA256(study_seed, JCS([source_id, split, model_cell, episode_rep, actor_slot, purpose, step_slot, namespace]))[:16]`; engine seed = `int.from_bytes(seed128,"big") & (2**63-1)`; collision check per cell (assert distinct engine seeds within an episode). Stateless banks: `actor_slot=0`, `step_slot=draw ordinal`, `purpose="ROOT"`, `namespace="MAIN"`. Nonstateless: DEC revision `purpose="DEC_REV"`, `actor_slot=member`, `step_slot=round`; hub `purpose="HUB"`, `step_slot=cycle`; worker `purpose="WORKER"`, `actor_slot=slot`, `step_slot=cycle`; consumer `purpose="CONSUMER"`, `actor_slot=child 1..4`. `study_seed` drawn once from `os.urandom(32)` and written to the freeze manifest before any request.
4. **MUST** request_id (§3.6): `SHA256(JCS([study_id, model_revision, tokenizer_revision, engine_digest, input_hash, decoding_hash, semantic_seed_hex, local_caps, hook_hash="none"]))` with `input_hash = SHA256(rendered chat-template bytes)`, `decoding_hash = SHA256(JCS(sampling dict incl. enable_thinking, guided_json flag))`, `local_caps = {"max_tokens":8192,"max_input":32768}`. Storage key = request_id; a second cell finding an existing request_id reads it (alias) and never regenerates.
5. **MUST** Prompt envelope with real token IDs (§4.3, §6.4): `tokenizer.apply_chat_template(messages, tokenize=True, add_generation_prompt=True, enable_thinking=<role>)` from the pinned snapshot; assert task-only render ≤ 4,096 and full render ≤ 32,768 for every request before enqueue; cross-check 1% of requests against the server's `/tokenize`. Preflight over all 460 items × 4 checkpoints for the root envelope.
6. **MUST** Evaluation isolation (§3.3, §10.6): generator/selector code imports only `study.data.public`; `study.evaluation` is the only module that opens `protected/`; a static fixture greps `study/{orchestration,selection,prompts,inference,resources}` for the tokens `answer\b`, `canonical_solution`, `"test"`, `protected` and fails on any hit; the public export is asserted to lack those keys at load.
7. **MUST** Seal order (§3.6, §10.3): `candidates.json` (per item, per method) written → `selection.json` (sealed pool IDs, vote keys, grouping_mode, chosen ID, tie counts, `sealed_at`) → only then `evaluate` may run; `evaluate` refuses if `selection.json` is missing or newer than its own start.
8. **MUST** Intention-to-run (§9.1): every scheduled (item, method, N, B, rep) stays in the denominator; invalid/timeout/context-failure → Y=0 with `terminal_status`; INFRA_INCOMPLETE (server down, exception) → ≤2 retries with the same request_id, then reported separately and the paired item flagged for exclusion from paired contrasts only (§10.4).
9. **MUST** Budget broker (§6.5, §10.2) — one `EpisodeLedger` per episode: `reserve(group)` computes Σ F(L_known_prefill, 8192) for each call in the indivisible group plus the method's final-decision reserve; launch only if `reserved + committed ≤ B`; on completion `debit(actual)` = F(L_actual_prefill, T_actual) and release the difference; stop optional work when the next legal group does not fit; log per episode: `B`, `committed`, `slack = B − committed`, `stop_reason ∈ {BUDGET, CALL_CAP, ROUND_CAP, CYCLE_CAP, VOLUNTARY_FINISH, CONTEXT_FAILURE}`, `calls_by_role`, `tokens_by_role_channel`, `peak_concurrency`. Thread-safe: a single lock around reserve/debit; parallel members of a round are reserved as one group before any launch.
10. **MUST** No overshoot (§6.5): `assert committed ≤ B` at episode close; violation → cell marked SUSPENDED (not scored), never silently trimmed.
11. **SHOULD** Store per request: messages, rendered bytes hash, token_ids, reasoning_content, content, finish_reason, usage, latency, endpoint, server profile, reservation/debit (§10.3).
12. **SHOULD** Prompt hashes for all rendered templates and the four framing cells per item in the freeze manifest (§5.5).

## 4. Statistics and reporting plan (runnable Monday 06:00 on partial data)

**Population rule (outcome-blind).** Each module's items are processed in salted-hash rank order, so completed items form a balanced prefix. For every contrast use the *smallest common completed prefix* across its arms (`n_common`), separately per superdomain; report `n_common` in every table. Never include an item for one arm and not the other.

**Weighting.** Statistic = 0.5·mean_HLE + 0.5·mean_BCB (§9.1); per-domain estimates shown beside.

**Bootstrap** (`study/statistics/bootstrap.py`, numpy, seeds in manifest): 20,000 resamples of source items independently within superdomain, keeping each item's full vector (all cells, prefixes, K); for a scalar contrast Δ, studentized t = Δ/SE_boot; null-centered p from the distribution of (Δ*−Δ)/SE* with the (+1)/(+1) correction (§9.3); two-sided for A and O, one-sided for C. 95% percentile intervals for display.

**Families (Holm over six, §9.2).** A: `0.5·((Y01−Y00)+(Y11−Y10))` on VOTE@5, n=N_main prefix. O: max |t| over the 10 pairwise contrasts of native B4 accuracy across the five methods (A1) in each centered resample → global p and simultaneous intervals at 0.05/6. C: mean(Brier_baseline − Brier_explicit) after dev-frozen recalibration, equal over three architectures. R, G, M: p=1. Holm step: sort the six p's; reject the k-th smallest iff p ≤ 0.05/(7−k) and all smaller rejected. Conservative display bounds at .05/6 per scalar family. Below 30 clusters in a superdomain → estimation-only label.

**Secondary (Holm within family):** S1 (framing interaction, candidate mean, coverage), S2 (N, d, IND_PRIVATE vs DEC_ONE_ROUND), S3 (checkpoint × architecture), S4 (pass@K, selection gaps, E panel), S5 (personal calibration, awareness inflation).

**Tables/figures producible Monday (§12.1):** Five-versus-five (one-draw, oracle pass@5, VOTE@5, JUDGE_BEST@5, alias, four cells); B4 native accuracy for five methods with slack/stop-reason companions (resource frontier reduced to one B, plus B1/B2 if tier 3 ran); membership N and degree d panels if tier 2 ran; calibration (PERSONAL_FINAL per cell, TEAM_SELECTED if C ran); reproducibility table (counts, exclusions, seeds, pins, alias counts, retries, judge audit rates). Not producible: internal dynamics, content mechanism, RLM/transfer.

**Reuse:** `analysis/nb_lib/calib.py` (brier_decomposition, signed_gap, cox_recalibration) for §9.5 diagnostics; write the cluster bootstrap fresh (nb_lib's `cluster_boot_mean` resamples design cells, not source items, and uses B=2,000).

## Disagreements
- Tier A does not 'alias F banks' for all methods: only IND_VOTE-11 (draws 0..9 from F11), S_FRESH-00 (F00), S_HISTORY's root (F00 draw 0), the 00 N-panel/degree/one-round-control roots (F00) alias. Main-tier DEC roots must carry the §4.1 truthful clause (experiment_matrix.yaml: root_framing native_truthful) and therefore never alias; CEN_FLAT never aliases. The DEC clause is not in the handoff and must be authored and frozen before the pilot (amendment A3).
- 'B4 will typically bind at the 64-call cap' and 'B8 may alias B4 exactly' are not established. §6.5 requires B0 from full-cap reservations over frozen envelopes (not pilot-observed lengths); a back-of-envelope oracle for Qwen3-32B suggests B4 admits roughly 35-45 realized root calls, so the FLOP budget likely binds before the call cap for IND/S_FRESH (and B8 would then be a distinct episode). Record stop_reason per episode and alias B8 only under the per-episode rule; tier-1 cost is probably ~50-60k gens rather than ~100k.
- The literal CODE_SELECTOR clause in prompts/framing_clauses.json cannot be used unchanged once the code vote falls back to AST/exact-source grouping; §5.5 requires the aware clause to be truthful, so the clause must be re-worded (amendment S1b) before any F bank is generated on BCB. The brief did not flag this.
- Setting B0 'in the dev pilot' must mean computing it analytically from the frozen envelopes and config.json dimensions (§6.5, §10.2), with the pilot used only to validate feasibility and throughput; observed pilot token counts must not enter B0.
- Using Qwen3-32B as the HLE correctness judge makes the solver judge itself with no human audit (§3.3). This is tolerable only with the MC-based judge-error audit and the 2-pp differential-error bound written into the manifest (amendment E1); the brief lists the judge but not the audit substitute.
- The C tier as described ('4 methods') cannot include CEN_RLM by default; C must be declared as a three-architecture family with TEAM_AFTER_EXTRA masked null, and it needs native episodes plus forecasts on all 60 dev items (not just the 20-item pilot) to fit the §8.7 recalibrator before any confirmation label join.
- The E panel at 30 items x 6 episodes is below the §9.3 30-cluster minimum per superdomain and cannot produce pass@10; it must be labeled estimation-only.
